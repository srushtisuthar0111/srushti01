## Quickstart

```powershell
# 1. Enter engine directory
cd matching_engine

# 2. Install package in editable mode
pip install -e .

# 3. Run demonstration match
python example.py

# Or run CLI module
python -m matching_engine
python -m matching_engine --json

# 4. Run test suite
python -m pytest -v
```
